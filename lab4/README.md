# 🍳 WhatToCook — Что приготовить из того, что есть

Консольное F# приложение: ведите «кладовку» продуктов дома и получайте идеи блюд через **TheMealDB API**.

## Возможности

| Функция | Описание |
|---------|----------|
| **Кладовка** | Добавляйте/удаляйте продукты (название, количество, единица, срок годности) |
| **Закончится скоро** | Продукты с ближайшим сроком → приоритет в рецептах |
| **Идеи блюд** | 3 секции: «Можно приготовить», «Почти можно», «Лучше съесть сейчас» |
| **Список покупок** | Автоматически из недостающих ингредиентов выбранных рецептов |

## Архитектура (ФП)

```
Domain.fs      — чистые типы, без I/O
Storage.fs     — JSON-персистенция (кладовка, покупки, кеш)
MealDbApi.fs   — async HTTP-клиент TheMealDB
Scoring.fs     — чистые функции ранжирования/классификации
Cli.fs         — интерактивный CLI (единственное место I/O)
Program.fs     — точка входа
```

Все бизнес-функции **чистые** (data in → data out). Побочные эффекты (I/O, HTTP) изолированы на границах.

## Скоринг рецептов

$$
score = \frac{matched}{total} + \min(0.6,\; 0.2 \times expiring) - 0.1 \times missing
$$

- `matched` — сколько ингредиентов рецепта есть в кладовке
- `expiring` — сколько из них «закончится скоро»
- `missing` — сколько не хватает

## Запуск

```bash
cd lab4
dotnet run
```

## API

- **Основной:** [TheMealDB](https://www.themealdb.com/api.php) (бесплатный, ключ `1` для разработки)
- **Запасной:** [Spoonacular](https://spoonacular.com/food-api) (требует API key, богаче данные)

## Хранение

Данные сохраняются в `~/.whattocook/`:
- `pantry.json` — кладовка
- `shopping.json` — список покупок
- `cache.json` — кеш ответов API (TTL 6 часов)
